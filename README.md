# KNDA17 · One-Q

Premium smart-home experience website.

- Website: https://heurogenesis.github.io/KNDA_LGD_17B/
- Static output: `site/`
- Deployment: `.github/workflows/pages.yml`

Enable **Settings → Pages → Source → GitHub Actions**, then run the Deploy GitHub Pages workflow. The website URL becomes available after a successful deployment.

This repository contains the static build, not the application source or original reference documents. Product demonstrations are simulations; concept product specifications are labeled as proposals.
